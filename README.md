# E-Commerce Customer Analytics

## Power BI Data Analytics Project

**E-Commerce Customer Analytics** is a data analytics and visualization project developed using **Microsoft Power BI**. The project analyzes e-commerce data to understand sales performance, product categories, customer geography, payment methods, returns, shipping costs, taxes, and traffic sources.

The project transforms raw e-commerce data into an **interactive Power BI dashboard** that makes important business information easier to explore and understand.

---

## Project Overview

E-commerce businesses generate large amounts of data from customer transactions, products, payments, returns, marketing channels, and financial activities.

Analyzing this information directly from raw tables can be difficult. This project uses **Power BI** to organize the available data and present it through interactive visualizations and key performance indicators.

### Dashboard allows users to:

- Monitor important business KPIs
- Analyze product category performance
- Explore customer distribution by country
- Compare payment methods
- Analyze returned orders
- Examine traffic sources and revenue
- Review shipping costs and taxes
- Filter the analysis by country, category, and date

---

## Objectives

The main objectives of this project are:

- Measure overall e-commerce performance using financial and operational indicators.
- Analyze product categories using quantity, revenue, and profit-related measures.
- Explore customer distribution across different countries.
- Examine transaction preferences through payment-method analysis.
- Analyze returns across product categories and time.
- Examine traffic sources and their relationship with revenue.
- Provide interactive filtering using Power BI slicers.
- Build a clear and user-friendly business intelligence dashboard.

## Dashboard Features

### 1. Key Performance Indicators

The dashboard includes KPI cards for important measures such as:

- Discounted Price
- Profit
- Quantity
- Tax

These provide a quick overview of overall e-commerce performance.

### 2. Product Category Analysis

Product categories can be compared using:

- Sales quantity
- Profit
- Revenue-related measures

This helps identify differences between sales volume and profitability.

### 3. Customer Geographic Analysis

The dashboard includes a geographic view of customer activity.

Users can:

- Compare activity across countries
- Identify countries with higher transaction activity
- Select a specific country using the dashboard filter
- Analyze other metrics for the selected market

### 4. Payment Method Analysis

The dashboard compares purchase quantities across different payment methods.

This provides a descriptive view of customer transaction preferences represented in the dataset.

### 5. Returns Analysis

Return analysis is included to understand return activity across:

- Product categories
- Years
- Months

### 6. Traffic Source Analysis

Traffic sources are analyzed in relation to revenue.

This provides a view of how different customer-acquisition channels are associated with revenue generation.

### 7. Shipping Cost & Tax Analysis

Shipping cost and tax are included as additional financial and operational measures.

This provides a broader view of transaction economics instead of focusing only on sales and profit.

### 8. Interactive Filters

The dashboard contains interactive filters for:

- Country
- Product Category
- Order Date

These filters allow users to move from an overall business view to a more focused analysis.
